# 중등학사 업무관리 툴 — 기획안 (v0.1)

> 작성일: 2026-10-11 · 상태: 계획 수립 단계 (구현 전)
> 참고 자료: 교육청 학사업무 매뉴얼 목차(5개 영역 96개 업무)

---

## 1. 목적과 대상

### 1.1 문제 정의
학사업무 매뉴얼은 **업무 담당자(부장·계원)** 관점으로 쓰여 있어, 일반 교과 교사는 다음을 바로 알기 어렵다.

- 이 업무 중 **"내가" 해야 하는 일**이 무엇인지 (담임 / 교과 / 전 교사 공통)
- **언제** 해야 하는지 (학사력상 시기, 마감)
- **왜** 해야 하는지 (법령·지침 근거) 와 어기면 생기는 문제
- 의무로 해야 하는 **법정 교육·연수**를 다 했는지

### 1.2 대상 사용자
| 사용자 | 주요 관심사 |
|---|---|
| 일반 교과 교사(비담임) | 수업·평가·학생부 교과세특, 결보강, 복무, 법정 연수 |
| 담임교사 | 위 내용 + 출결, 학생부 종합 기재, 상담, 사안 1차 대응, 학부모 소통 |
| 부서 계원(업무 분장 받은 교사) | 위 내용 + 담당 업무의 연간 절차·서식 |
| 신규·전입 교사 | 학교 업무 전체 지도(map) 파악 |

### 1.3 목표 (한 문장)
**"96개 학사업무를 교사 역할·시기·법령 기준으로 다시 묶어, 내가 이번 달에 무엇을 해야 하는지 한 화면에서 알려주는 도구"**

## 2. 설계 원칙

1. **학생 개인정보를 다루지 않는다.** 학생 이름·번호·출결·성적 등은 입력받지 않는다. 툴은 "업무 안내 + 개인 체크리스트"에 한정한다. (개인정보 보호법, 교육부 개인정보 보호지침 준수)
2. **외부 전송 없음.** 서버·외부 API 없이 정적 페이지(GitHub Pages)로 동작하고, 사용자 진행 상황은 브라우저 `localStorage`에만 저장한다. 메모 입력란에는 "학생 개인정보 입력 금지" 안내를 고정 표시한다.
3. **근거 우선.** 모든 업무 카드에 법령·지침 근거와 출처(국가법령정보센터 링크, 교육부·교육청 지침명)를 붙인다. 근거가 학교 자율이면 "법정 기구 아님 / 학교 규정" 으로 명시한다.
4. **최신성 표시.** 법령·지침은 매년 바뀌므로 항목마다 `최종 확인일`을 두고, 개정이 잦은 항목(교권, 학교폭력, 현장체험학습 등)은 "개정 주의" 배지를 단다.
5. **기존 저장소 관례 유지.** 현재 저장소는 빌드 도구 없이 `index.html` 단일 파일 + CDN + CSS 변수 테마 방식이다. 같은 방식(바닐라 JS, Pretendard 폰트, `:root` CSS 변수)을 따르되, 기존 `index.html`(학급임원선거 신청서)은 건드리지 않고 `/haksa/` 하위에 새로 만든다.

## 3. 정보 구조

### 3.1 원본 5개 영역 (매뉴얼 기준 그대로 유지)
| 코드 | 영역 | 항목 수 |
|---|---|---|
| A | 교무학사 | 19 |
| B | 교육과정 | 27 |
| C | 생활·안전 | 15 |
| D | 과학·수학·정보 | 12 |
| E | 체육·보건·급식·방과후 | 23 |
| | **합계** | **96** |

### 3.2 교사 관점의 추가 분류 축 (태그)
원본 영역은 그대로 두고, 아래 태그로 **다시 거르는** 구조로 만든다.

- **역할 태그** `role`
  - `공통` : 모든 교사가 직접 해야 함 (예: 복무, 법정 연수, 아동학대 신고의무)
  - `담임` : 담임교사가 직접 처리 (예: 출결, 학생부 행동특성 기재)
  - `교과` : 교과 수업·평가 담당으로서 처리 (예: 평가문항 제작, 교과세특)
  - `담당` : 업무 담당 부서만 처리, 일반 교사는 **협조·참여**만 (예: 정보공시, 급식 모니터링)
- **시기 태그** `months` : 3월~2월 학사력 기준 (복수 가능, 상시는 `0`)
- **유형 태그** `kind` : `절차`(행정 처리) · `교육`(학생 대상 의무교육) · `연수`(교원 대상) · `기구`(위원회·회의) · `기록`(학생부·나이스)
- **중요도** `priority` : `법정의무`(위반 시 제재·감사 지적) · `지침` · `권장`

### 3.3 업무 카드 데이터 스키마 (초안)
빌드 없이 타입 검사를 받기 위해 `// @ts-check` + JSDoc 타입을 사용한다.

```js
/**
 * @typedef {'공통'|'담임'|'교과'|'담당'} Role
 * @typedef {{ law: string, article?: string, url?: string, note?: string }} LegalBasis
 * @typedef {{
 *   id: string,              // 'A-02'
 *   area: 'A'|'B'|'C'|'D'|'E',
 *   no: number,              // 매뉴얼 번호
 *   title: string,           // '학교생활기록부 관리'
 *   summary: string,         // 교사용 2~3줄 요약
 *   roles: Role[],
 *   months: number[],        // [3, 7, 12, 2] / 상시 [0]
 *   kind: string[],
 *   priority: '법정의무'|'지침'|'권장',
 *   legal: LegalBasis[],
 *   todo: Partial<Record<Role, string[]>>,  // 역할별 할 일
 *   cautions: string[],      // 자주 틀리는 점, 기한
 *   checkedAt: string,       // '2026-10-11' 근거 최종 확인일
 *   revisionAlert?: string,  // 최근 개정 주의 문구
 * }} Duty
 */
```

예시:
```js
{
  id: 'A-04', area: 'A', no: 4, title: '학생 출결 관리',
  summary: '출결은 매일 나이스에 입력하고 증빙서류를 기한 내 받아 보관한다.',
  roles: ['담임', '교과'], months: [0], kind: ['기록'], priority: '법정의무',
  legal: [
    { law: '학교생활기록 작성 및 관리지침', note: '교육부 훈령' },
    { law: '학교생활기록부 기재요령', note: '출결상황' },
    { law: '초·중등교육법 시행령', article: '제50조', note: '수업일수 2/3 이상 출석 시 수료·졸업' },
  ],
  todo: {
    담임: ['매일 출결 확인 및 나이스 입력', '결석계·증빙서류 기한 내 수합(학교 규정 확인)', '월말 출결 마감'],
    교과: ['수업 시간 결과·지각 확인 후 담임에게 공유'],
  },
  cautions: ['미인정 결석 누적 시 학업중단 위기학생 연계(C-06)'],
  checkedAt: '2026-10-11',
}
```

## 4. 화면 구성 (MVP)

```
┌──────────────────────────────────────────────────────┐
│ 중등학사 업무관리        [내 역할: 담임 ▾] [🔍 검색]   │
├──────────────────────────────────────────────────────┤
│ [이번 달] [업무 전체] [법정 교육·연수] [학사력]        │  ← 탭
├──────────────────────────────────────────────────────┤
│ 10월 · 담임 기준 할 일 7건 (완료 3)                     │
│ ☑ 2학기 지필평가 문항 검토 (B-13)          법정의무    │
│ ☐ 학생부 교과세특 중간 점검 (A-02)          지침       │
│ ☐ 학교폭력 예방교육 2학기 실시 (C-03)       법정의무    │
│ ...                                                  │
└──────────────────────────────────────────────────────┘
```

| 탭 | 내용 |
|---|---|
| **이번 달** | 선택한 역할 + 현재 월 기준 할 일 목록, 체크 시 `localStorage` 저장 |
| **업무 전체** | 매뉴얼과 같은 5개 영역 아코디언 + 카드 그리드(첨부 이미지 UI 유지). 역할·유형·중요도 필터, 키워드 검색 |
| **업무 상세** (카드 클릭) | 요약 / 역할별 할 일 / 시기 / 법령 근거(링크) / 유의사항 / 관련 업무 / 개정 주의 |
| **법정 교육·연수** | 학생 대상 의무교육 시수 체크, 교원 법정 의무연수 이수 체크(연도별) |
| **학사력** | 3월~2월 월별 타임라인. 월 클릭 시 해당 업무 목록 |

부가 기능: 인쇄용 레이아웃(이번 달 할 일 A4 1장), 진행 상황 JSON 내보내기/가져오기(기기 이동용, 개인정보 없음), 다크 모드.

## 5. 법정 교육·연수 체크 (핵심 차별 기능)

일반 교사가 가장 자주 놓치는 영역이라 별도 탭으로 둔다. 시수·주기는 **매년 교육부·교육청 공문 기준으로 재확인**해야 하므로 데이터 파일에서 수정 가능하게 둔다.

### 5.1 학생 대상 의무교육 (담임·교과 협조)
| 교육 | 주요 근거 | 비고 |
|---|---|---|
| 안전교육 (7대 영역) | 학교안전사고 예방 및 보상에 관한 법률 제8조, 학교안전교육 실시 기준 고시 | 학년별 시수 기준 확인 |
| 학교폭력 예방교육 | 학교폭력예방 및 대책에 관한 법률 제15조 | 학기별 1회 이상 |
| 성교육·성폭력 예방 | 학교보건법 제9조의2, 성폭력방지 및 피해자보호 등에 관한 법률 제5조 | 연간 시수 지침 확인 |
| 흡연·음주·약물 오남용 예방 | 학교보건법 제9조, 국민건강증진법 | |
| 생명존중(자살예방) | 자살예방 및 생명존중문화 조성을 위한 법률 | |
| 아동학대 예방 | 아동복지법 | |
| 장애인식개선 | 장애인복지법 | |
| 인성교육 | 인성교육진흥법 | |

## 8. 파일 구조 (계획)

```
/ (기존 유지)
├─ index.html                 ← 기존 학급임원선거 신청서 (변경 없음)
└─ haksa/
   ├─ PLAN.md                 ← 이 문서
   ├─ index.html              ← 툴 화면 (탭 4개)
   ├─ app.js                  ← 렌더링·필터·체크 저장 (// @ts-check)
   ├─ style.css               ← :root CSS 변수 테마 + 다크모드
   └─ data/
      ├─ areas.js             ← 5개 영역 메타
      ├─ duties-a.js … duties-e.js  ← 영역별 업무 카드 데이터
      ├─ mandatory.js         ← 법정 교육·연수 목록(시수는 연도별 수정)
      └─ types.js             ← JSDoc 타입 정의
```

- 데이터는 `fetch` 대신 `<script>` 로 불러와 로컬 파일(`file://`)로 열어도 동작하게 한다.
- `localStorage` 키는 `haksa:v1:` 접두사, 접근은 모두 `try/catch` 처리(사파리 개인모드 등).
